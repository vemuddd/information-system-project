# Университет студенттерін басқару ақпараттық жүйесі

## Жоба туралы

Бұл жоба университет студенттері туралы ақпаратты басқаруға арналған ақпараттық жүйе.

## Жобаның мақсаты

Студенттер туралы ақпаратты сақтау және басқару.

## Негізгі функциялар

- Студент қосу
- Студент туралы ақпаратты көру
- Студентті іздеу
- Студент ақпаратын өзгерту
- Студентті өшіру
